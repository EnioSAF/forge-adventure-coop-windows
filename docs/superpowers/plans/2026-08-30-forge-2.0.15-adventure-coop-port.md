# Forge 2.0.15 Adventure Coop Port Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Porter le multijoueur Adventure validé sur Forge 2.0.13 vers la base officielle actuelle 2.0.15-SNAPSHOT, puis produire un ZIP Windows autonome et simple à partager par lien GitHub.

**Architecture:** Conserver Forge 2.0.15 comme base et réimplanter uniquement la couche Adventure multijoueur du fork historique. La connexion, le lobby et le transport réutilisent le réseau Forge actuel; un protocole Adventure dédié synchronise monde, joueurs, combats et récompenses. La distribution est une copie portable isolée avec ses propres données et journaux, jamais un remplacement de l'installation Forge existante.

**Tech Stack:** Java 17, Maven 3.9.8, libGDX, Netty, JUnit, PowerShell/batch Windows, GitHub Actions.

**Spec:** `docs/superpowers/specs/2026-08-29-forge-adventure-coop-windows-pack-design.md`

## Global Constraints

- Base exacte: `Card-Forge/forge` commit `ac8c59a8442de8c594d7336021072b8531e2cb36`, version `2.0.15-SNAPSHOT`.
- Source historique: branche `ForgeMTG-Adventure-Multiplayer`, commit `c1139d5c1f7ceb3e17ce50718a9929e9134867e2`.
- Ne jamais copier en bloc l'historique du fork: il contient des suppressions de ressources et des expériences sans rapport.
- Ne jamais lire, modifier ou déplacer l'installation Forge principale ni les vraies sauvegardes Adventure.
- Tous les essais utilisent des répertoires isolés et les sauvegardes jetables `TestHOST` / `TestCLIENT`.
- Java 17 est obligatoire au build et vérifié au lancement.
- Les deux participants doivent exécuter exactement le même build du pack; un écart doit produire un message clair, pas un retour silencieux au menu.
- Chaque étape de code suit un cycle test rouge, modification minimale, test vert, puis compilation des modules concernés.
- Le ZIP et le dépôt redistribué incluent la GPL-3.0, les modifications et le lien vers le code source correspondant.
